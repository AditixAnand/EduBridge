🚀EduBridge

EduBridge is a full-stack educational platform that provides interactive learning resources, quizzes, and AI-powered guidance for students. The platform helps learners explore Web Development, AI & ML, and career opportunities through a modern and user-friendly experience.

📌 Project Overview

EduBridge bridges the gap between learning and career guidance by combining structured educational content with AI-driven assistance.

Users can:

📚 Learn technical concepts
🧠 Practice with quizzes
🤖 Get AI-powered learning suggestions
🎯 Explore career guidance resources

⚙️ Installation & Setup
1️⃣ Clone the Repository
git clone https://github.com/AditixAnand/EduBridge.git
cd EduBridge

2️⃣ Create Virtual Environment (Recommended)
Windows
python -m venv venv
venv\Scripts\activate
macOS/Linux
python3 -m venv venv
source venv/bin/activate

3️⃣ Install Dependencies
cd backend
pip install flask python-dotenv openai

4️⃣ Run the Backend Server
python app.py

5️⃣ Launch the Frontend

Open index.html in your browser.

✅ Ensure frontend API calls point to:

http://127.0.0.1:5000/
