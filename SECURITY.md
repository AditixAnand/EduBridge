# Security Policy 🔐

We take the security of EduBridge seriously. Thank you for helping us keep the platform secure for everyone! Please review this policy to understand how to responsibly report vulnerabilities.

---

## 📅 Supported Versions

Only the latest stable version of EduBridge currently receives active security updates and patches.

| Version | Supported        |
| ------- | ---------------- |
| v1.0.x  | ✅ Supported     |
| < v1.0  | ❌ Not Supported |

---

## 📬 How to Report a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues.** Public disclosure can leave users exposed before a fix can be deployed.

To report a potential vulnerability responsibly:

1. Navigate to the **Security** tab at the top of the main repository page.
2. Click on **Vulnerability reporting** in the left sidebar to open a private advisory.
3. Alternatively, please contact the maintainer directly or open a detailed brief explaining the issue.

### Please include the following details in your report:

- A detailed description of the vulnerability and the potential impact.
- Clear, step-by-step instructions to reproduce the issue (including scripts or sample payloads if applicable).
- Any potential mitigation steps or fixes you suggest.

---

## ⏱️ Response and Disclosure Timeline

- **Acknowledgment:** You will receive an initial response acknowledging your report within 48 to 72 hours.
- **Status Updates:** We will keep you updated on our progress as we investigate and work toward a resolution.
- **Fix Timeline:** Once a vulnerability is verified, we aim to deploy a patch within 14 business days.

Thank you for your cooperation in protecting the community through responsible disclosure! 🚀
